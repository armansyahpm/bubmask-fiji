# BubMask-Fiji v0.1.0

Release date: 2026-06-02

This is the first public research-prototype release of BubMask-Fiji.

## Included

- Fiji/Jython script entry: `Plugins > UNSW > BubMask`.
- Portable project-folder discovery through `BUBMASK_FIJI_PROJECT`, Fiji
  preferences, or a first-run folder picker.
- Windows installer: `install_bubmask_fiji.ps1`.
- Python worker for Mask R-CNN inference, measurement, histogram, and export.
- User guide with screenshots and manual-bubble workflow video.
- Validation and UI feature reports.
- Model metadata for Original BubMask, UNSW Round 2, and UNSW Round 3.

## Default Model

The Fiji user interface defaults to:

```text
UNSW Round 3 fine-tune (provisional)
```

Round 2 remains packaged for comparison and validation because the held-out
COCO evaluation in this project showed stronger agreement metrics for Round 2
on the available validation/test sets.

## Install

Python requirement: this release requires **Python 3.10**. Python 3.11/3.12 are
not supported by the current TensorFlow/Keras Mask R-CNN dependency stack.

From PowerShell:

```powershell
git clone https://github.com/armansyahpm/bubmask-fiji.git
cd bubmask-fiji
.\install_bubmask_fiji.ps1 -FijiPath "C:\path\to\Fiji"
```

Restart Fiji, open an image, then run:

```text
Plugins > UNSW > BubMask
```

## Known Limitations

- This is a research prototype, not a Fiji update-site package.
- The installer is Windows-oriented.
- The model weights are large and distributed as GitHub Release assets rather
  than committed to git.
- Manual correction is supported, but inter-operator repeatability still needs
  formal validation.
- Round 3 is the UI default for continuity with the tested workflow, but it
  should still be treated as provisional in scientific writing.
